## 🧭 Why the split

LLMs are good with words and bad with calendars. In chart casting — solar-term boundaries, bureau selection, star placement — the errors that *look* right are the hardest to catch.

So this project separates the two:

| | Done by | Outcome |
|---|---|---|
| **Chart casting** | Deterministic algorithms | Same input, same chart, always. Auditable line by line |
| **Interpretation** | Your own model | Only translates symbols into language |

Switching models never changes the chart. If it disagrees with mainstream software, that's a bug — not a "different school".

## 🚀 Quick start

```bash
npm install

# Dev: Vite (5173) + proxy (8787) together
npm run dev

# Production
npm run build
npm start          # → http://127.0.0.1:8787
```

Requires Node 20+. The Node service does two things only: serve `dist/`, and forward browser requests to your model endpoint (to bypass CORS). Keys pass through memory once — never written to disk, never logged.

## 🔑 Bring your own model

Open **Connect model** at the top right:

- **Base URL** — any OpenAI-compatible endpoint, ending with `/v1`
- **API Key** — stored in this browser's localStorage only
- **Model** — type it, or hit *Test connection* to list available models

| Preset | Endpoint | Note |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | Good Chinese classical-text comprehension |
| OpenAI | `https://api.openai.com/v1` | Needs overseas network |
| Moonshot | `https://api.moonshot.cn/v1` | Long context |
| Zhipu GLM | `https://open.bigmodel.cn/api/paas/v4` | Direct in China |
| SiliconFlow | `https://api.siliconflow.cn/v1` | Multi-model aggregator |
| Ollama | `http://127.0.0.1:11434/v1` | Local, no key needed |

> On a pure static host (no Node service), requests go directly from the browser and the endpoint must allow CORS.

## 📐 Conventions

| Item | Rule |
|---|---|
| Year pillar | Split at Lichun (start of spring) |
| Month pillar | Split at *jie* (not *zhongqi*) |
| Day pillar | True solar time; **after 23:00 takes the next day** (late-zi hour, matching `pai_pan.py`) |
| Hour pillar | Five-rats method |
| Qi Men | Hour-based rotating plate; centre 5 always lodges in Kun |
| Zi Wei | Sanhe school; life palace by counting months back, hours forward |
| Flying stars | Prosperity judged by period; deviations > 3° suggest the substitution chart |
| Tarot | Reproducible via seed + time_factor |
| Date selection | 12 officers + almanac + clash check (simplified) |

Where schools disagree, the UI says so. No pretending there is one answer.

## 🔬 Method & sources

Every class of conclusion carries an evidence level, following the scheme from `fengshui.skill`:

| Mark | Meaning |
|---|---|
| ✅ | Original text verified (Wikisource, public domain) |
| 🧮 | Rule implemented as written, cross-checked against an independent source |
| 📖 | Attribution accepted, original not obtained |
| ⚖️ | School-specific convention / a judgement, not settled |

On the Bazi chart, **Ten Gods, na-yin, twelve stages and shensha** are all clickable — 40+ entries with plain-language gloss and citation, ported from `kanyu/glossary.py`.

## 🧪 Tests

13 snapshot cases covering the boundaries that actually break: late-zi hour, Lichun edge, unknown hour, yin/yang dun, locked-seed draws.

```bash
npm test           # compare against snapshots
npm test -- -u     # regenerate after a convention change — review the diff
npm run verify     # print three charts for manual cross-check
npm run mock       # fake endpoint to verify the streaming path
```

## ⚠️ Boundaries

- No readings are stored. Refresh clears everything
- No amulet sales, no "remedy" product recommendations
- Not a substitute for medical, legal or financial advice
- For cultural study and entertainment; no fatalistic claims
- Tarot faces are hand-drawn SVG, not Rider–Waite artwork
